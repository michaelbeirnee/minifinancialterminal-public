Protection is the tail loss removed before cost, measured by repricing today's contracts under past joint market/vol shocks — not a payoff picture. Cost is money only (spread paid, decay, borrow); giving up upside is shown separately because it is not a cash cost. Data

Every command on the platform — equities, macro, fixed income, options, crypto and more. All free data sources.

SELECT A COMMAND
How this tab works: pick a command on the left (or search — try "yield curve" or "rsi"), fill in the parameters, and press Run. Results appear as a table, chart automatically when they look like a time series, and can be exported as CSV.

Two ways to save: ★ Save keeps the command so you can re-run it later with fresh data; 💾 Save results keeps a snapshot of the data itself as of right now. Both live in the Saved tab.

Every command shows a guide for its menu, an explanation of each parameter, and a runnable example when you select it.
